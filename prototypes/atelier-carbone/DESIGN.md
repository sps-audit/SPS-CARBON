# Atelier Carbone — design prototype

Five standalone French pages demonstrate a proposed SPS-CARBON direction. This is a visual prototype with synthetic data, no authentication, uploads, external form submission or production calculations. Existing application files remain independent.

Palette: petrol #071f27, pale mineral #f3f6f2, white #ffffff, mint #29c792, warm signal #c08d42, secondary ink #526568. Archivo provides normal-width reading text and wide display typography.

Signature: an industrial site drawn as an original vector plan, connected to a trace from source to reviewed result. Asymmetric display compositions on the website; stable controls and practical tables in the workspace. No route curtains, ambient counters or cursor-following effects.

Pages: index (home), plateforme (guided workflow), preuves (records and evidence), accompagnement (services and local brief), espace (customer workspace). The shared example contains 60 tCO2e electricity and 40 tCO2e fuel. Other applicable sources remain outside the illustrated inventory. All factors are fictional.

Interaction QA: source selector; workflow steps; record search and selection; review and undo; offer tabs; local brief download; workspace task filters, assignment and completion; menu and keyboard focus; narrow viewport.
