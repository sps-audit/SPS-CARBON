# SPS-CARBON identity (2026 kit)

The visual wordmark is **SPS CARBON**. Use **SPS-CARBON** in running text, product names, URLs and file names. **SAFEPERFORM SOLUTIONS** is the parent company.

## Symbol

A carbon ring and an open C, drawn as a hexagon with softened corners. Its two parallel cuts on the right side read as a measured, descending trajectory; the website uses them as its graphic device. The letters of the wordmark are outlined, so the logo does not depend on any installed font.

## Files

| File | Use |
| --- | --- |
| `logo-dark.svg` | Petrol logo on white, ice or mist |
| `logo-light.svg` | Ice logo on petrol or another dark, solid background |
| `logo-viridian.svg` | Viridian symbol with petrol lettering, for controlled accents |
| `logo-stacked-dark.svg` / `logo-stacked-light.svg` | Vertical lockups |
| `symbol-dark.svg` / `symbol-light.svg` / `symbol-viridian.svg` | Symbol alone, where the name is already present |
| `wordmark-dark.svg` / `wordmark-light.svg` | Lettering alone |
| `favicon.svg`, `app-icon-*.png` | Browser tabs, home screens and installed app |

The SVG files are cropped to the artwork: leave free space around them of at least half the ring's width. Do not stretch, recolour outside the palette, outline or add a shadow.

## Type

Website text is set in Mona Sans (SIL Open Font License), self-hosted. The wordmark lettering is outlined and independent of it.
